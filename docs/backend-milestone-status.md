## 后续后端开工规则

1. 第二阶段功能不能直接写代码，先补一页任务上下文：问题、范围、API、DTO、状态机、权限、CSRF、错误码和验收命令。
2. 涉及管理员、退款、核销、真实支付、报表或生产部署时，先更新 `docs/api-contract.md` 与 `docs/security-checklist.md`，再写测试。
3. 只要影响前后端互通，提交前优先运行 `scripts/verify-integration.sh`；普通后端切片默认运行 `scripts/verify-backend.sh`。
4. 每个切片结束后更新 `docs/decision-log.md`，并交给子代理做只读审查。
