# 项目简报

## 项目目标

将景区票务系统重构为 FastAPI + React + Vite + Ant Design 项目，并通过文档、测试和安全清单沉淀完整开发工作流。

## 第一阶段 MVP

游客购票闭环：

- 手机号进入系统。
- 实名注册后下单。
- 浏览票种、日期、时段和余量。
- 创建待支付订单。
- 模拟支付成功后扣库存并生成票码。
- 查看我的订单。

## 非目标

- 不接真实支付。
- 不做管理员后台。
- 不做核销、退款、报表。
- 不把旧 Node 代码逐行翻译成 Python。

## 成功标准

- 后端 API 有测试覆盖。
- 前端能完整走通游客购票流程。
- 订单、支付、库存状态正确。
- 游客不能越权访问别人的订单。
- 关键决策记录在 `docs/decision-log.md`。
