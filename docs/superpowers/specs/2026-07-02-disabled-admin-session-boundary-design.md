# 禁用管理员既有 session 边界

## 问题

管理员登录时已经要求账号 `status = ENABLED`，但账号可能在登录后被禁用。后续后台请求不能只信任既有 session，否则禁用账号仍可能访问管理端接口。

## 范围

- 后台 session 校验读取关联管理员当前状态。
- 如果管理员状态不再是 `ENABLED`，撤销当前服务端 session。
- 对前端返回统一 `401 ADMIN_AUTH_REQUIRED`，不暴露账号是否被禁用。

## 边界

- 不新增管理员账号管理 API。
- 不批量清理该管理员所有历史 session。
- 不改变游客 session 或管理员登录失败的统一错误文案。

## 验收

- API 测试覆盖登录后被禁用的管理员不能继续访问 `/api/admin/auth/me`。
- 测试覆盖被拒绝的既有 session 会被服务端撤销。
