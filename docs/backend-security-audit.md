# 后端安全审查

日期：2026-07-01

范围：当前后端线程负责的 FastAPI API、DTO、数据库访问边界、会话/CSRF、错误响应和后端测试。不覆盖前端 UI 响应式、浏览器视觉验收、真实生产部署和第三方支付。

## 审查结论

- 第一阶段游客购票 MVP 的后端安全基线已由自动化测试覆盖。
- 第二阶段管理员认证与权限基座、后台订单只读 API、单张票码核销 API、批量核销 API、撤销核销 API、批量撤销核销 API、撤销核销原因审计、核销审计日志、核销/撤销失败尝试审计及 CSV/XLSX 导出、全单/部分模拟退款、退款审计日志及检索/CSV/XLSX 导出、模拟支付回调安全边界、支付/SMS/登录限流 provider 边界、后台订单 CSV/XLSX 导出已由自动化测试覆盖。
- 第二阶段后台报表能力已覆盖运营汇总、支付对账汇总及 CSV/XLSX、产品维度报表及 CSV/XLSX、日报/小时/月度趋势报表、趋势补零、趋势 CSV/XLSX 和同步导出行数上限；真实支付渠道结算文件、手续费、退款通知和真实渠道结算级财务对账仍需单独建模。
- 后台异步导出任务基础、文件格式筛选、filters 白名单、公开 filters 脱敏、requestId 关联、worker 状态机、worker 脚本输出脱敏、worker 循环入口、systemd 守护/清理模板、失败字段长度契约、失败任务手动/自动重试、自动重试延迟领取、RUNNING 超时回收、RUNNING 超时最终失败告警事件记录、本地孤儿文件补偿清理、本地文件清理、文件下载端点、存储/队列/告警 provider 边界已由自动化测试覆盖；生产对象存储、外部队列和真实外部告警仍需单独建模。
- 后台异步导出告警事件只读查询 API、汇总 API、确认 API、批量确认 API、关闭和重开 API、批量关闭 API、关闭筛选和汇总增强、去重静默、类型和格式筛选、删除 API、批量删除 API 已由自动化测试覆盖；真实 email/Slack/Webhook 通知、跨任务聚合、可配置静默窗口和前端页面仍由后续前端或真实通知切片处理。
- 后台异步订单明细 CSV/XLSX worker、核销审计 CSV/XLSX worker、核销失败审计 CSV/XLSX worker、退款审计 CSV/XLSX worker、支付对账 CSV/XLSX worker、产品维度报表 CSV/XLSX worker、日报趋势 CSV/XLSX worker、小时趋势 CSV/XLSX worker、月度趋势 CSV/XLSX worker 已由自动化测试覆盖。
- 状态变更接口均有 CSRF 检查；已登录后的订单、支付、取消和退出会再校验 CSRF token 与当前 session 保存的 hash。
- 游客登录接口已有 MVP 内存限速，降低手机号登录被自动化滥用的风险；生产多实例部署时需要迁移到 Redis、网关或负载均衡层全局限速。
- 游客订单、支付、取消和查看都从 session 读取 `visitor_id`，不信任前端提交归属字段。
- 公共 DTO、游客 DTO、成功响应和失败响应都有契约测试保护，避免前端误依赖内部字段或默认框架错误结构。
- 当前后端只有最小请求日志，记录 method/path/status/安全化 request id/耗时；测试已覆盖不记录 query、请求体、Cookie 或 CSRF，未处理 500 也会产生日志。后续新增业务日志、审计日志或异常上报前仍需补对应脱敏测试。
